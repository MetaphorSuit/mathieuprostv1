### Building a blog, 20 years after the trend 

The main idea behind this project was to create an old school blog. My old self was a teenager during the 2000 era, and i've been an early adopter of those blogs that was spreading in France at that time. 

I consider it a simpler time, when using web was not directly affiliated with social media and the need to log in to apps and fight or bend the algorithm to get some visibility.

Most of social interactions online are concentrated into a few entry points - Tiktok, instagram, etc. And this has not always been like that 

>I wanted to create my own space, where people can find chunks and sparks of creativity, free from algorithmic sorting. And the most direct way to do that is most likely a good ol' fashioned blog. 


### Tech choices, needs, use case

- I want to write articles from my PKM, and upload chunks of my written notes online without having to log in to a GUI

- I want to be able to improve my website dynamically from a nice IDE on my cozy laptop, and the changes to be pushed online automatically in alignment with the Continuous Implementation / Continuous Development principles.

- I want to be able to close the file form 6 months and take back exactly where i left, without remembering anything, yet, the project being fully ready and functional.

- I need to alter, change, improve continously without interrupting the delivery between development and production.

### I want to use open source / free softwares : 

- **Obsidian** as a PKM and markdown GUI to write and manage my local files

- **Github** for CI/CD, built on top of Git for versionning purposes.

- **Hugo**,a static website generator (built with Git et Go)

- **a VPS** with my own DNS to display my website and put my own name on it.
